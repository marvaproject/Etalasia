# Etalasia

Etalasia adalah website katalog affiliate untuk produk Shopee dan TikTok. Admin mengelola kategori, produk, banner promo, dan link affiliate dari dashboard Filament, sementara halaman publik dibuat ringan dan mobile-first.

## Local URLs
- Katalog publik: `http://127.0.0.1:8000`
- Dashboard admin: `http://127.0.0.1:8000/admin`
